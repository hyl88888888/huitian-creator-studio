# 回天创作台

面向个人 IP、新媒体和电商的一站式 Windows 短视频工作台。它先把自然语言要求拆成可执行规则，再生成创作蓝图、逐句文案、分镜和本地粗剪。

## 直接使用

1. 打开 `release` 文件夹中的 Windows 安装包。
2. 新建项目后，只需在大输入框中说清“想做什么内容”；零散想法也可以。
3. 口播、图片和截图都可不传；平台、观众、目标、经历、时长、CTA、对标等在“高级设置”里全部选填。
4. 确认软件对要求的理解后，生成蓝图、文案和分镜。
5. 在导出页生成成片与“剪映友好素材包”。

软件首次启动使用本地兜底能力，不联网也能走完流程。需要高质量语义创作时，在“设置”里打开“联网高级创作”并填入一次访问密钥；官方 OpenAI 地址默认通过 Responses API 调用 `gpt-5.6`。需要素材不足时自动补画，再打开第二个开关即可。联网模型和素材生成会产生对应服务商的 API 费用，因此两个开关默认关闭，避免意外计费。

## 已实现

- 个人 IP、新媒体、电商三种创作流程
- IP / 品牌档案、素材库和视觉模板
- 对标链接与对标视频入口，可分别标记学习文案、画面或两者
- 把“从人性出发”“每句话与观众有关”“不能让人觉得关我屁事”等抽象要求拆成规则
- 冲突、缺失信息和深度采访问题
- 创作蓝图与逐句文案编辑
- 默认生成 3 篇不同策略的候选稿，经过六维量表评审和独立批判改写后择优
- 每句“关我何事”检查、关联度评分、锁定、版本保存与可见的选择报告
- 从用户锁定和人工改写中形成有界偏好记忆；偏好不修改程序代码，也不能覆盖事实和硬约束
- 官方 OpenAI 连接默认使用 `gpt-5.6` 与 Responses API；文案采用多稿探索、规则评审、独立批判改写和最终择优，不把一次回答直接当成成稿
- “回天融合导演”按每句话的表达任务选择一个主画面方法和最多两个辅助方法，不把整条视频套成某一个博主
- 七类可执行视觉语法：高密度解释、蒙版字效、动机组接、照片变化、生活叙事、多层空间舞台、实拍/录屏演示
- 对标方法统一转译到回天浅色品牌系统，并在分镜中显示取材来源、组合理由和具体制作步骤
- 自动分镜、口播底片、图片与视频 B-roll、截图推近、轻量调色和角色化中文字幕预览
- 上传素材永远优先；素材缺口可按当前句语义自动补原创图片或动态视频，默认图片优先，也可选择只在真正需要运动的镜头调用视频生成
- 联网生成默认使用 `gpt-image-2` 和 `sora-2-pro`；接口失败、超时或未开启时自动换成本地原创编辑视觉卡，不中断导出
- 每次导出真正发起联网素材任务前，软件会显示预计图片数与最多视频数，可选择继续、只用本地原创画面或取消；单次导出最多生成 3 个视频镜头，其余使用原创图片加本地运镜
- 视频任务创建后会在本机保存最小任务号；断网、超时或重新导出同一请求时优先恢复原任务，避免重复创建付费任务
- 软件不在画面上额外叠加自有“AI生成”大字；导出包内部保留生成服务、模型和提示词等来源记录，也不会移除第三方强制的水印或内容凭证
- 本地 FFmpeg 生成 1080×1920 成片与无字幕粗剪
- 导出 SRT、样式 ASS、CSV、时间线 JSON、编号素材、原创视觉素材、剪映导入说明和 ZIP
- 本机自动保存；模型密钥使用 Windows 安全存储加密，保存后界面进程只保留占位符，实际调用由后台完成

## 导出给剪映

导出目录包含：

- `final_preview.mp4`：带字幕预览
- `clean_roughcut.mp4`：无硬字幕粗剪
- `captions.srt`：可编辑字幕
- `captions_styled.ass`：预览成片使用的分角色字幕样式
- `shotlist.csv`：镜头起止时间与动效说明
- `timeline.json`：本软件时间线备份
- `media`：编号后的原素材
- `generated-originals`：软件补齐的原创图片、视频或本地编辑视觉卡片（有需要时出现）
- `generated-originals/generated-media-manifest.json`：生成来源、模型、提示词和回退记录
- `剪映导入说明.txt`

当前交付的是稳定的“剪映友好素材包”，不是剪映原生草稿。剪映草稿格式没有稳定公开的跨版本接口，直接伪造工程容易损坏项目。

## 当前边界

- 粘贴短视频链接目前会保存为对标来源，但不会绕过平台限制抓取视频；需要上传有权使用的对标视频。自动转写、OCR 和链接解析需要后续接入合规服务。
- 写实图片和视频生成已经接入，但需要用户自己的服务访问密钥、联网、可用额度和对应模型权限；离线状态会使用本地原创视觉卡。配音、数字人和基于真人参考图的一致角色生成尚未接入。
- OpenAI 已公告 Sora 2 / Videos API 将于 2026-09-24 停止。V0.3 保留当前可用通道用于内部试验，并允许修改视频模型与接口；正式收费发布前必须接入届时仍受支持的替代视频服务。图片生成与本地动态兜底不依赖该通道。
- 自动剪辑已覆盖竖屏铺满、基础调色、口播底片、图片/视频 B-roll、轻推近、场景交接和分角色字幕。自动镜头检测、逐词转写、主体跟踪、发丝级抠像和复杂三维动效仍在后续路线中。
- 目前是可运行的单机 MVP，未包含账号、云同步、授权码、套餐和支付。若要正式收费，应增加许可/订阅服务、用量计费、隐私协议和内容合规审核。
- 当前随包的 `ffmpeg-static` 经本机核验启用了 GPL、libx264 和 libx265。V0.3 安装包只用于内部试用；正式收费发行前，必须更换为许可证可证明合规的构建，或完整履行对应 GPL/LGPL 义务。选型记录见 `docs/OPEN_SOURCE_STACK.md`。

## 数据与联网

- 项目、档案和设置默认保存在本机的系统应用数据目录。
- 原始素材不会因为打开软件就自动上传；只有你主动发起相应联网创作时，完成任务所需的文字、对标信息或待生成画面的描述才会发送给已配置的服务。
- 本地基础引擎和视频渲染可离线工作。
- 只有启用外部模型服务并主动创作时，项目文本才会发送到用户自行配置的接口。
- 远程接口必须使用 HTTPS；只有本机服务允许 HTTP。无效地址会直接阻止，不会把密钥改发到默认服务。
- 偏好记忆保存在本机；调用外部模型时，会和本次创作要求一起发送给该接口以便应用用户风格。

## 开发与验证

项目使用 Electron、React、TypeScript、Zustand 和 FFmpeg。

```powershell
pnpm install
pnpm dev
pnpm typecheck
pnpm test
pnpm build
node scripts/smoke-electron.mjs
node scripts/verify-export.mjs
pnpm dist:win
```

自动测试覆盖完整六步创作流程、本地语义规则、逐句文案、分镜，以及带口播音轨和截图叠加的实际视频导出。
